# Voldi Mbayo Interactive Portfolio

A cinematic, scroll-driven portfolio built as an immersive developer experience.

## About

Voldi Mbayo is a Full-Stack & Mobile Developer and founder of Havenlabs, focused on building thoughtful digital products across web, mobile, APIs, and product design.

## Highlights

- Dark red-and-black visual direction
- Interactive WebGL scene powered by Three.js
- Procedural 3D technology icons
- Scroll-linked motion and depth effects
- Responsive layout for desktop and mobile
- Lightweight static deployment with no build step

## Featured work

- TalentGrid
- EK Talk Helper
- VoFa Link

## Run locally

Open `index.html` in a browser. For the most reliable module loading, serve the folder with any simple local web server.
